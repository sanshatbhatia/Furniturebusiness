# Remaster project

Cloning Haixun (https://www.hisoonsoft.com/) in app mode: Clone an app: its features and flows, rebuilt clean, better and yours.

- `state.json`: stage, decisions and gate results
- `features.csv`: the feature matrix, scored by `remaster parity`
- `sources.csv`: every source read, with its link and date
- `brand.json`: the original's names, domains and colors the sweep keeps out
- `research/`: reviews, pains, recon map, measurements of the original. Never published.
- `design/`: the original's measured system and yours
- `verify/`: measurements of the clone, diffs, critic verdicts, bugs, beat metrics
- `launch/`: listing, proof for any claim
